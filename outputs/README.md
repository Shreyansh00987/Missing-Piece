# Missing Piece: Output Artifacts Directory

This directory contains the experimental execution outputs, evaluation caches, and summary records generated by the Missing Piece benchmark suite.

## File Manifest

| File / Subdirectory | Description |
| :--- | :--- |
| `cache/` | Persistent line-by-line JSONL cache files for all evaluated models and baselines. Enables instant resumption without recomputing inference. |
| `cache/SmolLM2-135M-Instruct_responses.jsonl` | Complete raw model inference logs for SmolLM2-135M across all 120 benchmark items (prompt, raw response, latency in ms, UTC timestamp). |
| `cache/baseline_always_answer_responses.jsonl` | Baseline evaluation log for Always-Answer heuristic control. |
| `cache/baseline_always_abstain_responses.jsonl` | Baseline evaluation log for Always-Abstain heuristic control. |
| `cache/baseline_random_choice_responses.jsonl` | Baseline evaluation log for Random-Choice heuristic control. |
| `scored_results.csv` | Full tabular evaluation results containing every item's ground truth, model output, parsed status, outcome classification, and correctness flag. |
| `model_summaries.json` | JSON structured summary of all aggregate metrics and 95% Wilson score confidence intervals for each evaluated model. |
| `summary_table.md` | Markdown formatted leaderboard table ready for scientific publications and documentation. |
